# 🌵 Wild West Snake

Um jogo clássico da cobrinha totalmente customizado com a temática de **Velho Oeste**, desenvolvido com **React** e estilizado com **CSS puro**. 

### 🤠 Sobre o Jogo
Nesta versão, a cobrinha usa uma skin de xerife com chapéu de marrom clássico e linguinha bifurcada em movimento, correndo atrás de maçãs do deserto.
